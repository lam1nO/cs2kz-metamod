# Звания GYMSTRIKE KZ

- Для ранговой приписки и `!rank` используй `totalPoints`, `rankIndex`, `rankName` и `rankNextPoints` из `GET /v1/players/:steamId64/kz/summary?mode=…`, той же сводки, что использует профиль на сайте. Пороги званий зависят от пула карт и режима.
- При смене режима и отключении игрока сбрасывай сводку и привязку к запросу. При сбое обновления сохраняй последнюю успешно загруженную сводку текущего режима.
- После финиша обновляй ранг ещё раз за пределами 30-секундного кэша сводки, чтобы ответ из кэша не задерживал новое звание до очередного периодического запроса.
